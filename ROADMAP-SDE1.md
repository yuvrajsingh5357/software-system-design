# Roadmap: SDE-1

This roadmap is executable. Follow the Study -> Practice -> Exit Criteria loop.

## Phase 1: Language & Fundamentals
**Study:** Master Java 17+ core syntax and `01-complexity-and-big-o.md`.
**Practice:** Implement standard ArrayList and HashMap locally.
**Expected Outcome:** Write syntax flawlessly.
**Exit Criteria:** Can write a basic Java class without IDE autocomplete.

## Phase 2: DSA Core Patterns
**Study:** `01-dsa/16-pattern-recognition-guide.md` and `22-pattern-recognition-tests.md`.
**Practice:** Solve 50 problems from `01-dsa/17-sde1-problem-set.md` (Level 0 and 1). Use `21-randomized-practice-guide.md`.
**Expected Outcome:** Immediately recognize Sliding Window, Two Pointers, DFS.
**Exit Criteria:** Solve an unseen Easy array/string problem in 15 mins.

## Phase 3: DSA Intermediate Patterns
**Study:** `13-recursion.md`, `14-backtracking.md`, `15-bit-manipulation.md`.
**Practice:** Solve 75 Medium problems from `17-sde1-problem-set.md`. Use strict 35-minute timers (`19-timed-interview-practice.md`).
**Expected Outcome:** Fluency in Backtracking, Graphs, 1D DP.
**Exit Criteria:** Solve an unseen Medium graph or backtracking problem in 35 mins.

## Phase 4: Basic OOD & SOLID
**Study:** `03-lld/01-solid-and-oop-design.md`, `02-design-patterns/07-pattern-selection-exercises.md`.
**Practice:** Do the 15 exercises in `03-lld/09-solid-refactoring-exercises.md`.
**Expected Outcome:** Recognize God Classes, switch statement hell.
**Exit Criteria:** Refactor bad code strictly following OCP and SRP.

## Phase 5: Interview Simulation
**Study:** `00-interview-prep/02-answer-frameworks.md`.
**Practice:** Execute the 10 SDE-1 mock rounds in `06-coding-interview-simulations.md`.
**Expected Outcome:** Communication under pressure.
**Exit Criteria:** Pass a simulated 45-minute mock with a partner, explaining space/time complexity accurately.
