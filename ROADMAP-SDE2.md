# Roadmap: SDE-2

This roadmap is executable. Follow the Study -> Practice -> Exit Criteria loop.

## Phase 1: DSA Refresher & Speed
**Study:** Review `01-dsa/16-pattern-recognition-guide.md` and `22-pattern-recognition-tests.md`.
**Practice:** 30-40 Medium problems from `17-sde1-problem-set.md` blindly.
**Expected Outcome:** Regain coding speed and edge-case handling.
**Exit Criteria:** Flawless execution of standard mediums in <20 mins.

## Phase 2: Advanced DSA
**Study:** `01-dsa/20-advanced-graph-dp-theory.md` (Interval DP, Tarjan, etc.).
**Practice:** Solve 150 Hard problems from `01-dsa/18-sde2-problem-set.md`.
**Expected Outcome:** Mastery of state-machine DP, Trie, Union Find.
**Exit Criteria:** Can define states and transitions for a 2D DP problem in 5 mins.

## Phase 3: SOLID & Design Patterns Mastery
**Study:** `02-design-patterns/06-pattern-selection-guide.md` and `07-pattern-selection-exercises.md`.
**Practice:** `03-lld/09-solid-refactoring-exercises.md` and `03-lld/12-lld-follow-up-practice.md`.
**Expected Outcome:** Know *when not to use* a pattern.
**Exit Criteria:** Refactor legacy code into Strategy/Factory patterns seamlessly.

## Phase 4: Machine Coding & LLD
**Study:** `03-lld/10-machine-coding/01-introduction-and-evaluation.md`.
**Practice:** Code the 9 systems (Parking Lot, Rate Limiter, Splitwise) in `03-lld/10-machine-coding/` from scratch.
**Expected Outcome:** Production-ready code in 90 mins.
**Exit Criteria:** Complete the Splitwise machine coding with JUnit tests in 90 mins.

## Phase 5: Concurrency in Java
**Study:** `03-lld/11-concurrency-for-lld.md`.
**Practice:** Complete the 5 exercises in `03-lld/11-concurrency-for-lld-exercises.md`.
**Expected Outcome:** Deep understanding of `volatile`, `Atomic`, locks.
**Exit Criteria:** Design a concurrent Rate Limiter without `synchronized` methods.

## Phase 6: Interview Simulation
**Study:** Follow-ups in all case studies.
**Practice:** Execute the 10 SDE-2 Mock Rounds in `06-coding-interview-simulations.md`.
**Expected Outcome:** Graceful handling of scalability follow-ups.
**Exit Criteria:** Defend system design choices under heavy cross-examination.
