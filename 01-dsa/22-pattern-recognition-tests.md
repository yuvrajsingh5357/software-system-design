# Pattern Recognition Tests

Read the problem statement. Write down the algorithmic pattern. Do NOT code it. 
This tests pure recognition speed.

### Problem 1
You are given a list of interval pairs. Find the minimum number of intervals you need to remove to make the rest non-overlapping.
<details><summary>Answer</summary>Greedy / Sorting by end time.</details>

### Problem 2
Given a string, find the longest palindromic substring.
<details><summary>Answer</summary>2D DP or Expand Around Center (Two Pointers).</details>

### Problem 3
Given a list of words, find if there is a sequence of one-letter transformations to get from startWord to targetWord.
<details><summary>Answer</summary>BFS (Shortest Path in unweighted graph).</details>

### Problem 4
You have a continuous stream of numbers. Design a class that can quickly return the median at any point.
<details><summary>Answer</summary>Two Heaps (Max Heap for left half, Min Heap for right half).</details>

### Problem 5
Find the maximum subarray sum in an array of positive and negative integers.
<details><summary>Answer</summary>Kadane's Algorithm (1D DP).</details>
