# Randomized Practice Guide

At an interview, you don't know the topic beforehand. 
If you only practice DP problems while reading the DP chapter, you are not testing your pattern recognition.

## How to use this guide

1. Use a random number generator between 1 and 400 (representing the combined 150+250 problems in this repo).
2. Look up the problem by index in the master lists.
3. Set a strict timer (35 minutes).
4. Hide the "Topic" and "Pattern" metadata before reading.

## The 5-Minute Rule
If you cannot identify the pattern in 5 minutes, DO NOT start coding. 
1. Write out an example.
2. Find the brute force.
3. Look at constraints (e.g. N=10^5 means $O(N)$ or $O(N \log N)$).
4. If still stuck, look at Hint 1.
