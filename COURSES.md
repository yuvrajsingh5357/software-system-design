# Recommended Courses & Learning Paths

Curated resources for mastering Software System Design — DSA through HLD.

---

## 🎯 Learning Paths by Goal

### Path 1: Crack FAANG DSA Interviews
1. **DSA Fundamentals** → [Striver's A2Z DSA Course](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/)
2. **Practice** → [LeetCode Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions)
3. **Advanced Problems** → [Codeforces](https://codeforces.com/) / [AtCoder](https://atcoder.jp/)

### Path 2: Ace LLD Interviews
1. **OOP & SOLID** → Head First Design Patterns (book)
2. **Design Patterns in Java** → [Refactoring.Guru](https://refactoring.guru/design-patterns)
3. **Practice LLD** → [Workat.tech LLD Problems](https://workat.tech/machine-coding)

### Path 3: Ace HLD Interviews
1. **System Design Fundamentals** → [ByteByteGo Newsletter](https://blog.bytebytego.com/)
2. **Deep Reference** → Designing Data-Intensive Applications (DDIA) — Martin Kleppmann
3. **Case Studies** → [System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer)

## 🗺️ 12-Week Study Plan (Interviews in 3 Months)

| Week | Focus | Goal |
|------|-------|------|
| 1–2 | DSA: Arrays, Strings, Hashing | Solve 30 easy LeetCode |
| 3–4 | DSA: Trees, Linked Lists, Stack/Queue | Solve 20 medium LeetCode |
| 5 | DSA: Graphs, Heaps | BFS/DFS fluency |
| 6 | DSA: DP, Greedy | Core DP patterns |
| 7 | Design Patterns: Creational + Structural | Implement in Java |
| 8 | Design Patterns: Behavioral | Implement in Java |
| 9 | LLD: OOP, SOLID, 3 case studies | Full implementations |
| 10 | LLD: 3 more case studies + review | Mock LLD interviews |
| 11 | HLD: Building blocks, DB, Cache, Queue | DDIA chapters 1–6 |
| 12 | HLD: Case studies + Mock interviews | 5 full system designs |

## 🔥 High-Signal Practice List

### DSA (LeetCode Problems)
- Two Sum, Container With Most Water (Two pointers)
- Merge Intervals, Meeting Rooms (Sorting)
- Maximum Subarray (Kadane's / DP)
- Word Ladder (BFS)
- Number of Islands (DFS/BFS)
- Coin Change, Longest Common Subsequence (DP)
- Top K Frequent Elements (Heap)
- LRU Cache (HashMap + Doubly Linked List)

### LLD Problems
- Design a Parking Lot
- Design an ATM
- Design Chess
- Design a Library Management System
- Design Uber (at class level)

### HLD Problems
- Design URL Shortener
- Design Twitter / News Feed
- Design WhatsApp
- Design YouTube
- Design a Rate Limiter

---

*For each problem, aim to: understand requirements → design classes/components → code it → identify patterns used → find failure modes.*
